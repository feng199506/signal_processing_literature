独立目录：/root/signal_processing_literature/。覆盖本科信号与系统到研究生专题、应用与工程部署。检索日 2026-10-30；论文五年窗口 2021-10-30 至 2026-10-30，必要经典单列。

本轮只收集整理：不安装依赖、不运行实验、不连接采集设备、不部署、不上传 GitHub、不删除资料。
